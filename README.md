# Ponte 🌉

> Read real Italian from day one. Understand more than you think.

Ponte is a parallel-text Italian reader built for intermediate English speakers who already know Spanish. It surfaces the structural advantage Spanish speakers have in Italian — highlighting cognates, flagging false friends, and calling out grammar divergences — so you spend less time confused and more time actually reading.

No login. No gamification. No build step. Open `index.html` and read.

---

## How to run

```
open index.html
```

That's it. No server, no dependencies, no install.

---

## Features

- **Parallel text reader** — Italian on the right, English or Spanish translation on the left
- **EN / ES toggle** — switch the translation column between English and Spanish at any time
- **Color-coded word intelligence**
  - 🔵 **Blue** — Cognate: same meaning as Spanish, safe to assume
  - 🟡 **Yellow** — False Friend: looks Spanish but means something different
  - 🟠 **Orange** — Divergence: similar word, but used differently in Italian
  - ⚪ **White** — New vocabulary with no Spanish anchor
- **Tooltip cards** — tap any highlighted word for its English meaning, Spanish equivalent, and a usage note
- **Mobile-friendly** — columns stack vertically on small screens, Italian on top
